# Revenge Plugins

このリポジトリでは、Discordクライアント改造 [Revenge](https://github.com/revenge-mod/revenge) 向けのプラグインを複数公開しています。

- [YouTube Rich Presence](#youtube-rich-presence) — 見ているYouTube動画をDiscordのステータスに表示
- [宅建クイズ (Takken Quiz)](#宅建クイズ-takken-quiz) — 宅建士試験対策のクイズ

各プラグインの導入方法は、それぞれのセクションを参照してください。

## YouTube Rich Presence

見ているYouTube動画のURLを貼ると、タイトル・チャンネル名・サムネイルを自動取得して、Discordのステータスに「視聴中」として表示するRevengeプラグインです。

**注意:** これは他のローカル表示専用プラグイン (例: Avatar Override) とは違い、実際にDiscordのステータスとして送信されます。フレンドや同じサーバーの人など、あなたのプロフィールを見られる人には表示内容が見えます。

### インストール方法

1. Revengeの `設定 > プラグイン` を開きます。
2. 右上の「+」からリポジトリURLとして次を追加します。
   ```
   https://hihei56.github.io/revenge-youtube-rpc-/youtube-rpc/
   ```
3. 一覧に出てくる `YouTube Rich Presence` をインストールして有効化します。
4. プラグインの設定画面を開きます。
   - **動画URL / プレイリストURL**: 見ているYouTube動画のURL (`https://youtu.be/...` や `https://www.youtube.com/watch?v=...`)、またはプレイリストのURL (`https://www.youtube.com/playlist?list=...`) を貼り付け、「情報を取得」をタップします。
   - プレイリストのURLを貼った場合は、プレイリスト内の動画一覧 (最大15件、YouTube側の仕様) が表示され、タップした動画がそのまま「視聴中」として表示されます。最初は先頭の動画が自動で選ばれます。
   - **自動シャッフル**: プレイリストに2件以上の動画がある場合に表示される「5分ごとにランダムな他の動画へ切り替える」をオンにすると、5分ごとにプレイリスト内の別の動画へ自動で切り替わります。直前に表示していた動画は除外して選ぶため、同じ動画が連続することはありません。「ステータスに表示する」がオフの間や、AFKモード中は切り替わりません。
   - タイトル・チャンネル名・サムネイルが自動で取得され、プレビューに表示されます。必要ならタイトル・チャンネル名は手動で編集できます。チャンネル名は「(チャンネル名)を視聴中」のように、ステータスの一番上の行に表示されます。
   - 「ステータスに表示する」をオンにすると、実際にDiscordのステータスとして送信されます。別の動画に切り替えたいときは、新しいURLで「情報を取得」をやり直してください (オンのままなら自動で更新されます)。
   - オフにする、またはプラグインを無効化すると、ステータスは消えます。
   - ステータスには「動画を見る」ボタンが付きますが、Discordの仕様上**自分の画面では表示されません** (フレンドなど他の人から見た時だけ表示され、押すとその動画に飛べます)。これは実際のゲームのRich Presenceでも同じ仕様です。
   - **AFKモード**: 寝ている時や離席中など、YouTube視聴中の表示に関係なく固定の文言 (例: 「😴 寝ています」) を優先して表示できます。オンの間はYouTube側の設定より優先されます。

> GitHub Pagesの反映には初回のみ数分かかることがあります。上記URLが404になる場合は少し待ってから再度お試しください。

### 仕組み

- タイトル・チャンネル名・サムネイルの取得には、YouTube公式の oEmbed API (`https://www.youtube.com/oembed`) を使用しています。APIキーは不要です。
- プレイリスト内の動画一覧の取得には、YouTube公式のAtomフィード (`https://www.youtube.com/feeds/videos.xml?playlist_id=...`) を使用しています。こちらもAPIキー不要ですが、最大15件までしか返らないというYouTube側の仕様があります。フィード取得に失敗した場合のみ、プレイリストページ自体のメタ情報 (`og:title` / `og:image`) から取得します。
- ステータスの表示には、DiscordクライアントがローカルのAI活動検出 (ゲームプレイ中表示など) に内部で使っているのと同じ仕組み (`LOCAL_ACTIVITY_UPDATE` というFlux アクション) を直接発行しています。これはVencordの `CustomRPC` や、Revenge/Bunny向けに実際に公開されている `CustomRPC` プラグインと同じ手法です。
- サムネイル画像は、そのままのURLではDiscordのステータス画像として使えないため、Discord公式の外部アセットプロキシ (`applications/0/external-assets`) に一度変換してから使用しています。
- 自動シャッフルは、プレイリスト取得時にキャッシュした動画一覧 (プラグインのストレージに保存) から、直前に表示していた動画を除いた中でランダムに1件選び直すことで実現しています。5分ごとの定期チェックはプラグインの読み込み中ずっと動作し続け、実際に切り替えるかどうかは毎回そのタイミングで自動シャッフル/プレイリスト状態/ステータス表示/AFKモードの設定を見て判断します。
- 完全自動でYouTubeアプリの再生中動画を検知することはできません。Revengeのプラグインは Discordアプリ内のJavaScriptとしてのみ動作するため、別アプリ (YouTubeアプリなど) が何を再生しているかを直接知る手段がないためです。動画URLを貼る操作は手動で行う必要があります。

保存データはプラグインのストレージ (`@vendetta/plugin` の `storage`) に保持されます。

- モバイル版Discord (Revenge) 専用です。
- ステータスは実際にDiscordのサーバーに送信され、他のユーザーに見えます。ローカル表示専用のプラグインではありません。
- Discordのアプリ内部実装の変更で、動作しなくなる可能性があります。

## 宅建クイズ (Takken Quiz)

宅地建物取引士試験の対策クイズです。「○×モード」と、宅建名物の"個数問題"を出題する「hell級モード」を分野別に挑戦でき、XP・レベル・コンボといったソシャゲ風の要素で学習のモチベーションを維持します。

### 特徴

- **○×モード**: 1問1答形式。制限時間 (12秒) 内にテンポよく正誤を判定します。
- **個数問題モード (hell級)**: 4つの記述 (ア〜エ) のうち正しいものがいくつあるかを答える、宅建試験で難易度の高い出題形式です。制限時間は30秒。
- **分野別 or 全分野ランダム**: 権利関係・宅建業法・法令上の制限・税その他の4分野から選んで挑戦できます。
- **想起学習ベースの出題**: 間違えた問題や、しばらく出題していない問題を優先的に出す (簡易的な間隔反復) ので、単調な暗記になりません。
- **XP・レベル・称号・コンボ**: 正解するとXPを獲得し、レベルと称号 (「宅建ひよこ」〜「伝説の宅建士」) が上がっていきます。連続正解でコンボボーナスも発生します。
- **学習履歴**: 分野別の正答率と、直近の挑戦履歴を確認できます。

### インストール方法

1. Revengeの `設定 > プラグイン` を開きます。
2. 右上の「+」からリポジトリURLとして次を追加します。
   ```
   https://hihei56.github.io/revenge-youtube-rpc-/takken/
   ```
3. 一覧に出てくる `宅建クイズ (Takken Quiz)` をインストールして有効化します。
4. プラグインの設定画面を開くと、そのままホーム画面 (ステータス・モード選択) が表示されます。モードと分野を選んで「スタート」をタップすれば挑戦できます。

チャットで `/宅建` と入力すると、現在のレベルや正答率などの簡易ステータスをDMやサーバーのチャンネルからいつでも確認できます (本体の出題・回答はプラグイン設定画面から行います)。

> GitHub Pagesの反映には初回のみ数分かかることがあります。上記URLが404になる場合は少し待ってから再度お試しください。

### 注意事項

- 収録している問題は学習用に作成したものであり、実際の過去問そのものではありません。法改正等で内容が変わる場合があるため、正式な学習教材と併用してご利用ください。
- 保存データ (XP・履歴・問題ごとの正答状況) はプラグインのストレージ (`@vendetta/plugin` の `storage`) に保持され、端末外には送信されません。

## ソースからビルドする場合

```sh
npm install
npm run build
```

`dist/<プラグイン名>/` にビルド済みの `manifest.json` と `index.js` が出力されます。
`main` ブランチへのpushで `.github/workflows/deploy.yml` が自動的にビルドし、GitHub Pagesへデプロイします
(pushイベントで自動起動しない場合は、GitHubのActionsタブから手動で "Run workflow" してください)。
